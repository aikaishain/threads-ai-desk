# 03. 競合分析

対象の切り口：**#8 中小企業の一人広報・個人事業主が、顔出しせずAIアバター動画で紹介動画を量産する**（02_niche.md の決定事項）

調査日：2026-10-26

---

## 0. 調査方法と限界（必読）

- `competitors_input.md` は無いので、WebSearch／WebFetchで公開Web上の情報だけを使って調べました。
- **Threads上の競合アカウントは確認できませんでした。** `threads.net` を指定したり、「HeyGen 顔出しなし」などで検索したりしましたが、Threads投稿は検索結果に出てきませんでした（02_niche.md と同じ限界です）。X・Instagram・YouTubeの**個人発信者**についても、検索で具体的なアカウント名やフォロワー数を確かめることはできませんでした。
- そのため下の表は「同じ悩み（顔出しせずに動画を作る／AIアバターで紹介動画を作る）に向けて、Web上で情報や解決策を出している発信者・事業者」を競合とみなして整理しています。**SNS上の直接の競合が少ないのか、検索で拾えないだけなのかは未確認です。**
- 精度を上げるため、ユーザー自身が Threads・X・Instagram で「HeyGen」「AIアバター」「顔出しなし 動画」「一人広報」などを検索し、目についたアカウントのプロフィール文・投稿の例（3〜5件）を `threads-design/competitors_input.md` に貼り付けてもらうようお願いします。貼り付けてもらえれば、この分析を追記・修正します。
- 表は「事実（確認できたこと）」と「考察（そこから考えたこと）」を分けて書いています。考察は推測を含みます。

## 2. 共通パターン（競合の「あるある」）

1. **機能・料金の解説が中心**：法人メディアや公式サイトの多くは「HeyGenとは」「料金プラン」「使い方」の網羅型。「実際に何本作って、何時間かかって、何が困ったか」という運用記録はごく少ない（#4のレビューくらい）。
2. **読者が両極に分かれている**：
   - 「AIアバター動画の**制作代行で稼ぐ**副業希望者」向け（#3、#8）
   - 「社長・大企業」向けの法人ソリューション（#6、#7）
   - 間にいる「**自分の事業の動画を、自分ひとりで作りたい小規模事業者・一人広報**」に向けた発信は、確認できた範囲ではほとんどない（#5がターゲットとしては近いが、制作を引き受ける側）。
3. **出口は自社サービス**：自社サイトへの会員登録、制作代行、自社AI製品、サロンなど、自社の商品へつなぐ形が多い。HeyGenのアフィリエイトをはっきり打ち出した日本語の個人発信は、確認できた範囲では#4だけ（計測パラメータ付きのリンク）。
4. **料金情報がばらばら**：同じHeyGenでも記事によって「Creator 29ドル」「月額49ドルから」と書き方が違い、プランの改定に追いついていない可能性がある（どちらが最新かは未確認）。
5. **リスクの説明は一般論**：肖像権、著作権、「不気味の谷」は多くの記事が触れるが、「顔出しNGの本人が**身バレしない**ためにどのアバターを選ぶか」という目線では書かれていない。
6. **SNSネイティブな発信が見えない**：見つかった情報はブログ・メディア・プレスリリース・ココナラが中心。Threadsで短い文章を使ってこのテーマを続けて発信しているアカウントは、検索では確認できなかった（未確認）。

## 3. 空白（差別化できるポイント）

### 空白1：「作る側の副業」ではなく「使う側本人」の継続運用ログ
- 根拠：競合は「代行で稼ぐ」（#3）か「法人向け」（#6、#7）に分かれ、#4も単発のレビュー。
- 差別化案：顔出しNGの本人として、自分のアカウント用の動画をAIアバターで作り続ける記録（1本の制作時間、修正の回数、かかった費用、反応）を数字で出す。一人広報・個人事業主が「自分でもできそうか」を判断する材料になる。
- 注意：ユーザー本人は一人広報ではないので、当事者のふりはしない。「顔出しNGで発信している立場として試した」という形にとどめる。

### 空白2：「身バレしない度合い」でアバターの選び方を比べる
- 根拠：既製のアバター、フォトアバター、自分そっくりのデジタルツインという選択肢があること自体は各所で紹介されている。しかし「匿名性」「本人とばれるリスク」「声のクローンを使うかどうか」を軸にした比較は見当たらない。
- 差別化案：「顔も声も出したくない人は既製アバター＋合成音声」「顔はNGだが声はOKの人は〜」のように段階的に選び方を整理する。ユーザー自身の運用条件（匿名・顔出しNG）とそのまま重なる。

### 空白3：日本の小規模事業者が実際につまずく点を正直に記録する
- 根拠：日本語の口の動き、グリーンバックの輪郭（#4が言及）、ドル建ての月額課金、記事ごとに違う料金情報、インボイスや経費処理（未確認）など、実務で困る点がまとめて整理されていない。
- 差別化案：「契約前に確認すること」「無料プランでどこまで試せるか」「プラン改定で変わった点」を、公式ページを確認した日付付きで発信する。料金の食い違いを放置している競合が多いので、情報が新しいこと自体が信頼の材料になる。

### 空白4：Threadsで「文章と動画を組み合わせて」発信する
- 根拠：競合の多くはSEO記事・プレスリリース・出品ページで、Threadsで続けて発信しているアカウントは確認できなかった（未確認）。
- 差別化案：Threadsのテキスト投稿で「台本の型」「1本作るのにかかった時間」を短く出し、実際に作ったアバター動画を添えて見せる。「この投稿の動画もAIアバターで作った」という実物を見せることが、そのまま説得力になる。

### 空白5：AIであることの表示とPR表記を最初から徹底する
- 根拠：上場企業の事例では、本人とアバターを区別する印を付ける運用が紹介されている（[Business Insider Japan](https://www.businessinsider.jp/article/255836/)を検索結果の要約で確認。本文は未確認）。一方、個人や小規模の発信ではAI生成であることの表示や広告表記の扱いがまちまちに見える（例：#3は本文で広告表記を確認できなかった）。
- 差別化案：動画に「AIアバターです」と表示し、アフィリエイトリンクには「PR」と書くことを習慣にする。一人広報・個人事業主が自社で使うときにも真似できる「誠実な使い方のテンプレート」として打ち出す。ステマ規制への対応にもなる。

## 4. 次の工程（persona-designer）への申し送り

- 「制作代行で稼ぎたい副業層」と「自社の動画を自分で作りたい一人広報・個人事業主」はニーズがまったく違う。ペルソナは後者に絞るのがこの切り口の空白と合っている（推測）。
- 市場規模（顔出しせずに動画を作りたい小規模事業者がThreadsにどれだけいるか）は今回も**未確認**。ユーザーに `competitors_input.md` へ実際のアカウント情報を貼ってもらえれば、ここを補える。
- HeyGenのアフィリエイト条件（3か月間35%）は02_niche.mdで確認済み。最新の料金プランは公式ページで改めて確認してから使うこと。
