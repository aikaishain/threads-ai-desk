# 06. コンセプト作成

作成日：2026-10-26

---

## 0. 前提（立ち位置）

- ユーザー本人は個人事業主でも一人広報でもない会社員。顔出しせず、AIで短編動画を作っている人。**ペルソナ（副業の個人事業主・一人広報）の当事者のふりはしない。**
- 発信者の立ち位置は「顔も声も出さずAI動画を作っている会社員が、自分で試した結果を共有する人」。読者より半歩先を歩く「試す人」であり、先生や成功者ではない。
- 副業実績は3,000円程度。実績は盛らず、「ゼロから挑戦する過程を公開する」型にする。
- 数字（制作時間、費用、修正回数）は自分が実測したものだけを使う。料金・無料枠は公式ページで確認した日付つきで出す（未確認のものは書かない）。

| どうやって | 発信者自身が顔出しNGの会社員として、AIアバター・合成音声ツールを実際に試し、結果を毎回数字つきで公開する。動画には「AIアバターです」、リンクには「PR」を必ず付ける。自分の経験（ChatGPT、Claude Code、短編動画の作成・編集）を「半歩先の試した人」として使う。弱点も隠さない |
| どうなってもらうか（誇張なし） | 「自分の場合、何分・いくらで1本作れそうか」「顔・声を出さない選択肢のどれが合うか」を、契約前に自分で判断できる状態になる。集客や収入の増加は約束しない |

## 4. おすすめ

**おすすめ：A「顔も声も出さず、AI動画づくりを試す会社員の記録」**

理由
1. 本人の実態（会社員、匿名、顔出しNG、AIで動画を作っている、実績はまだ小さい）を一切盛らずに言える。当事者のふりが不要。
2. 「試す」「記録」という語が、成果を約束せず過程を公開する型に合っており、誇張を避けやすい。副業の警戒心が強い読者（05のV5、V6）にも受け入れられやすい。
3. 「顔も声も」と並べることで、05の軸A（身バレ）を声まで含めて表現でき、「会社員」と書くことでペルソナ（副業バレが怖い会社員）との同類感が出る。軸B（時間）は柱の中身（制作ログ）で補う。
4. B・C・Eの要素は、発信の柱として吸収できる（B：制作ログ、C：身バレ度の選び方、E：日付つき正直レビュー）。

注意：「会社員」と出すことは身バレ要素にならないよう、業種・会社規模・地域・勤続年数などは出さない（00のNG「身バレするような内容は発信しない」）。

## 6. 約束してよいこと／してはいけないこと

| 約束してよい | 約束しない |
|---|---|
| 自分が試した結果（時間、費用、修正回数）を実測で出す | 「顔出しなしで集客できる」「申込が増える」 |
| 料金・無料枠は確認日つきで出す | 「誰でも簡単」「月◯万円」 |
| AIアバターには「AIアバターです」、リンクには「PR」を付ける | 「身バレしない」と言い切ること（「しにくい」「確認すること」にとどめる） |
| 弱点（口の動き、AI臭、ドル払い）も書く | 税・副業規定・給付などの断定（公式・専門家へ誘導） |

## 7. 未確認事項・次工程への申し送り

- HeyGenの最新料金・無料枠・日本円決済・インボイス対応は未確認。投稿前に公式ページで確認する。
- A8.netの案件は a8_programs_input.md が空のため未確認。ユーザーに05の案件カテゴリを検索して貼ってもらう必要がある。
- Threads上の競合・需要は未確認のまま（市場が小さい可能性）。運用開始後の反応で検証する。
- ポジショニング設計（07）では、「試す人」という立ち位置と、「半歩先を歩く会社員」としての語り口を軸にする。
- 本人の実際の制作時間・費用の実測がまだ無いので、最初の数投稿で記録を取り始めること。

## 決定

決定：C「身バレしないAI動画の作り方を、実測で試す人」（2026-10-26）

**注記（表現の調整）**：評価時に指摘された通り、「身バレしない」は成果保証に近い言い回しです。実際の投稿・プロフィール・固定投稿では、断定を避けて次のように言い換えて使ってください。
- 「身バレしにくい」「身バレのリスクを下げる」
- 「身バレ対策を実測で検証する」
- 「〇〇の設定にすると、本人が見ても気づきにくかった（個人の体験）」のように、主観・実体験の範囲であることを明記する
