# 02. 穴場ジャンル発掘（ニッチ切り口の比較）

## 0. 前提・調査方法の注記

- `01_genre.md` で選ばれた上位3サブジャンル（①AIノーコード／アプリ開発ツール紹介、②AI動画生成ツール紹介、③生成AIスクール紹介）すべてを対象に、「誰に×何を×どんな状況で」で切り口を細分化し、穴場度を調査しました。
- **重要な制約（未確認事項）**：WebSearchツールはThreads（threads.net）の投稿を直接検索・件数集計することができませんでした（`site:threads.net` 等で試行しましたが、Threads上の投稿はインデックスされず取得できませんでした）。そのため「Threads上の発信者の多さ」は、note・ブログ・X・比較サイトなど**公開Web上の言及量を代理指標とした推測**であり、Threads内の実際の投稿密度そのものを直接確認したものではありません。この点は各切り口の判定でも明記します。
- 運用条件（匿名・顔出しNG、1日2時間程度）は判定の前提として踏まえていますが、ジャンル選定の優先軸自体は「高単価アフィリエイト」「競合の少なさ」です（ユーザー本人の経歴適性は主軸ではなく、補足的な「真似されにくさ」の観点としてのみ使用）。

## 2. 穴場トップ3の詳細

### トップ1：#8 中小企業の一人広報・個人事業主が、顔出しせずAIアバター動画で紹介動画を量産する（元：②AI動画生成ツール紹介）

**なぜ空いていると考えられるか**
- HeyGen・Synthesiaの日本語記事は「機能紹介」「料金比較」が中心で（[HeyGen使い方・活用事例](https://weel.co.jp/?p=69553)、[HeyGen vs Synthesia比較](https://www.heygen.com/ja-jp/alternatives/heygen-vs-synthesia)）、「顔出しせずに集客動画を作る」という運用目線・継続目線の発信は見当たりませんでした（**推測**：需要自体は「顔出ししたくない個人事業主・広報担当」という一定数の層に存在すると考えられますが、裏付けとなる検索データは未確認）。
- 一人広報・兼務担当者の「工数が負担で更新が止まる」という課題は実際に指摘されており（[中小企業の一人広報向け解説](https://www.koukoku.jp/service/suketto/marketer/sns/%e6%96%b0%e8%88%88sns%e3%81%ae%e6%8a%95%e7%a8%bf%e3%82%b3%e3%83%b3%e3%83%86%e3%83%b3%e3%83%84%e3%82%92ai%e3%81%a7%e8%87%aa%e5%8b%95%e5%8c%96%e3%81%99%e3%82%8b%e6%96%b9%e6%b3%95%ef%bd%9c%e5%85%bc/)）、悩みの実在は確認できています。これに「AIアバターなら話者本人が顔出しせずに動画を量産できる」という解決策を重ねる発信は少ないと見られます（推測）。
- **ユーザー自身の運用条件（顔出しNG・匿名）とこの切り口が直接重なる**点が最大の強みです。「顔出しできない自分が、顔出しせず集客動画を作る方法を試して発信する」という構造は、同じ悩みを持つ読者への説得力が高く、模倣されても「本人の悩みから出た発信」という文脈は再現しにくいと考えられます。

**収益化の導線（確認済み）**
- HeyGen公式アフィリエイトプログラムを確認：新規契約の紹介ごとに3か月間35%の継続コミッション、報酬上限なし、クリックから30日間のラストクリック有効、PayPalで月次支払い・最低30ドルから（[HeyGen公式アフィリエイトページ](https://www.heygen.com/ja-jp/affiliate-program)）。海外ツールのため日本円での受け取り・税務処理は別途確認が必要です（**未確認**）。
- Vrewについては日本語でのアフィリエイト・A8提携の有無を確認できませんでした（**未確認**。公式サイトまたはA8.net管理画面で個別確認が必要）。

**リスク**
- 市場規模が未確認：「顔出ししたくない個人事業主・一人広報」がThreadsにどれだけ存在し、実際に月額課金ツールを契約するかのデータがありません（**未確認・市場が小さすぎる可能性**）。
- 海外SaaSのため、日本語サポート・請求方法・インボイス対応などで読者が離脱するリスクがあります。
- 「AI生成動画は見た目が不自然（AI臭）」という指摘もあり（Vrewレビューより類推）、動画生成AIツール全般に品質面のハードルがある点は留意が必要です。

### トップ2：#1 医療・介護・福祉の現場職が、職場専用ツールをClaude Codeで自作する（元：①AIノーコード／アプリ開発ツール紹介）

**なぜ空いていると考えられるか**
- 検索で、医療職の非エンジニアがClaude Codeで職場のシフト管理アプリを自作した体験記（「月額16,000円のClaude Code Maxプランで3週間で2本自作」）、放課後等デイサービス専門のシフト管理ツールを約2週間で自作した体験記が見つかりました。いずれも**個人の単発note/ブログ記事**であり、比較サイトやアフィリエイト目的で量産的に発信しているアカウントは見当たりませんでした（推測：競合は少ない段階にあると考えられます）。
- Claude Code／AI開発そのものの発信は技術者・個人開発者向けが主流（切り口#4, #5参照）で、「IT知識のない現場職員が、既製品にない自分の職場専用ツールを自作する」という目線は相対的に手薄と見られます。
- 悩みの実在：「既製品では現場だけの仕様が実現できない」という課題が実際の体験記で言及されており、需要の存在を示す一次情報があります（[放課後等デイサービス向けシフト管理ツール自作記事](https://library.libecity.com/articles/01KWS96PXKSMTNZNEHBW27GJNE) ※タイトル・要約から推測、全文は未確認）。

**収益化の導線**
- Claude Code／Cursor等の有料プラン紹介自体は単価が小さいと見られます（推測）。高単価化には「未経験からAI開発・業務改善を学べるスクール」への送客を組み合わせる必要がありますが、医療・介護業界向けに特化したAI開発スクールの存在・報酬額は**未確認**です。
- ノーコード制作の外注代行（ランサーズ・ココナラ等での受託）への誘導も考えられますが、これはアフィリエイトではなく役務提供になるため、今回の「高単価アフィリエイト」軸とは別の収益モデルになります（注記）。

**リスク**
- 対象読者（現場スタッフ）は組織の決裁権を持たないことが多く、個人の購買力・ツール課金への意思決定力が小さい可能性があります（推測）。
- 医療・介護現場は個人情報保護・システム要件が厳格で、「自作ツール」が実運用に耐えるかという専門的ハードルがあり、誤った情報発信は実害（個人情報漏洩等）につながるリスクがあります。発信する場合は「自己判断で使わず専門家に相談を」等の注意書きが必須です。
- ユーザー本人は医療・介護業界の経験がない（00_profile_inputでは「業界の知識・資格：特になし」）ため、現場のリアリティを伴う発信ができるかは未確認の懸念点です。AI実績にある「運動指導書」はリハビリ・健康領域と重なる可能性がありますが、これは推測の域です。

- ユーザー本人は30代であり、この切り口での「自分の属性との重なり」は直接的ではありません（会社員という点のみ共通）。

## 4. おすすめ

**おすすめ：#8「中小企業の一人広報・個人事業主が、顔出しせずAIアバター動画で紹介動画を量産する」**

理由：
1. 運用条件（顔出しNG・匿名・1日2時間）と切り口そのものが一致しており、無理なく継続できる。「顔出しできない自分がどう解決したか」を発信するため、再現されにくい一次情報になりやすい。
2. 収益化の導線（HeyGenアフィリエイト：3か月35%継続コミッション、上限なし）が今回の調査で唯一「公式ページで確認済み」の具体的な条件であり、他2候補（スクール送客・AI開発スクール送客）は報酬額が未確認のままである点で優位。
3. 競合密度は「推測」の域を出ないが、日本語の発信が機能紹介中心に留まっていることは確認できており、「需要がないから競合が少ない」のではなく「一人広報・個人事業主の工数負担」という実在の悩みに対する解決策の提示がまだ少ない、という構図が見えている。

一方で、市場規模そのもの（顔出しNGで動画集客をしたい事業者がThreads上にどれだけいるか）は未確認であり、小さすぎる可能性は残る。これは次工程（競合分析・ペルソナ設計）で検証を続ける必要がある。
