# A8.net案件リスト（ユーザーが貼り付ける入力ファイル）

A8.netの管理画面にはAIがログインできないため、ここにユーザーが案件情報を貼り付けてください。
needs-analyst（05_needs.md）とpost-creator（10_posts_draft.md）がこのファイルを読みます。

## 貼り付け方
案件ごとに以下の項目を書く（分かる範囲でOK）。

```
- 案件名：
- カテゴリ：（例：AIスクール、AIツール、動画生成AI など）
- 報酬額／報酬率：
- 承認条件：（例：無料登録のみ／有料プラン契約後 など）
- Cookie期間：
- 備考：
```

## 貼り付け例

```
- 案件名：〇〇AIスクール（入会プラン）
- カテゴリ：AIスクール
- 報酬額／報酬率：30,000円／件
- 承認条件：有料プラン契約後
- Cookie期間：30日
- 備考：教育訓練給付金対応コースあり
```
