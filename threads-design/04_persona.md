# 04. ペルソナ設計

対象の切り口：**#8 中小企業の一人広報・個人事業主が、顔出しせずAIアバター動画で紹介動画を量産する**（02_niche.md の決定事項）

作成日：2026-10-26

---

## 0. 前提と設計方針

- 03_competitors.md の申し送りに従い、「AIアバター動画の**制作代行で稼ぎたい副業層**」ではなく、「**自分の事業・自社の動画を自分ひとりで作りたい人**」にペルソナを絞りました。
- 「ユーザー本人の過去の姿に近いほど説得力が出る」というルールに沿って、メインペルソナは**会社員を続けながら副業で小さな個人事業をしていて、本業バレ・身バレが怖くて顔出しできない人**にしました。00_profile_input.md と重なる部分には【00と重なる】と書いています。
- サブペルソナは「中小企業で広報を兼務している一人広報」です。メインとは状況（会社のお金で契約する立場）とAIの理解度（ほぼ未経験）が違います。
- 名前・年収・スケジュールなどは**設計上の架空の設定**で、統計に基づく数字ではありません。統計を使った箇所は出典を付けています。
- 性別はユーザー本人の情報に無いので仮に決めています。投稿の言葉づかいに大きく影響する場合は、ユーザーの実感に近いほうへ変えてください。

### ペルソナの裏付けに使える外部データ（WebSearchで確認）

| 内容 | 出典 | 注意点 |
|---|---|---|
| Threads利用者のうち18〜34歳の割合は41%（2023年11月時点） | [Web担当者Forum（ニールセン デジタル調べ）](https://webtan.impress.co.jp/n/2024/02/05/46453) | 2年以上前のデータ。現在の年齢構成は未確認 |
| 日本のThreads利用時間は前年比+130%（Meta発表、2026年7月の3周年時） | 検索結果の要約で確認（[ケータイ Watch](https://k-tai.watch.impress.co.jp/docs/news/2121644.html)、[INTERNET Watch](https://www.watch.impress.co.jp/docs/news/2121668.html)） | 本文は未確認。年齢別の内訳は出ていない |
| 日本パブリックリレーションズ協会が「ひとり広報」の実態調査をしている（2023年2月、有効回答183人） | [PRSJ 調査資料](https://prsj.or.jp/association/wp-content/uploads/2023/06/document20230601.pdf) | 「ひとり広報が全体の何%か」は確認できなかった（**未確認**） |

- 「SNSで顔出ししたくない人の割合」を直接示す最近の調査は見つかりませんでした（**未確認**）。投稿で「〇割の人が顔出ししたくない」のような数字は使わないでください。

### AIの理解度

- **ChatGPTを少し使った**レベル。レッスンの案内文やInstagramのキャプションを書いてもらう程度で、無料版がメイン。
- 動画はスマホの編集アプリでテロップを入れたことはあるが、AIで動画を作ったことは無い。
- 「HeyGen」という名前は、Threadsで見かけて保存したことがあるだけ。英語の画面・ドル建ての支払いに少し身構えている。
- 【00との違い】ユーザー本人はClaude Codeでアプリを作ったり、短編動画の作成・編集をしたりしている。ペルソナはそれより**一歩手前**にいる。ユーザーは「少し先を歩いている人」として教えられる位置にいる。

### 動画（AIアバター）を始めたい理由

1. 講座の集客をInstagramとThreadsでしているが、テキストと画像だけでは申込みが増えない。**「動画で講師の人柄やレッスンの雰囲気が伝わるほうが申し込まれやすい」**と同業者から聞いた。
2. でも顔を出すと、**会社の人や保育園のママ友に副業がバレる**かもしれない。【00と重なる：匿名希望・身バレNG】
3. 撮影は、子どもが寝たあとの夜しかできない。照明・メイク・撮り直しの時間が取れない。
4. 「顔を出さずに、自分の代わりに話してくれる動画」があれば、集客を続けられるのでは、と考えている。
5. 本音の目標：副業を月5万円くらいにして、将来は会社に頼りすぎない働き方にしたい。【00と重なる：本業以外の収入を育てたい（00の目標は月10万円・1年後に本業を辞められるくらい）】

### これまでの挫折

- 顔出しなしで、文字だけのリール動画を作ったが、3本で止まった（1本作るのに2時間かかった）。
- フリー素材の写真＋音声読み上げの動画を試したが、「機械っぽくて安っぽい」と感じて投稿できなかった。
- SNS運用の講座（数万円）を買ったが、「顔出しして毎日発信しよう」が前提で、自分には合わなかった。
- Threadsでの発信も、毎日投稿を2週間続けたあと止まった。
- 【00と重なる】副業の実績は小さい（ユーザー本人は3,000円程度）。「少しは動いたけれど、大きくは伸びていない」段階が共通している。

### お金・時間・知識の制約

| 制約 | 内容 |
|---|---|
| お金 | 副業に使えるのは**月数千円まで**が本音。家計は夫と共有なので、高い月額課金は言い出しにくい。ドル建て・年払いは特に身構える |
| 時間 | 平日夜の1〜1.5時間と土曜の夜だけ。**「1本作るのに何時間かかるか」が最大の判断材料** |
| 知識 | 英語のツール画面が苦手。台本の書き方、アバターの選び方、商用利用・肖像権のルールがよくわからない。インボイスや経費の扱いも不安 |
| 心理 | 「AIっぽい動画で、かえって怪しまれないか」「お客さんにAIだとバレたら信用が落ちないか」が心配 |

### よく使うSNS・フォローしているアカウントの傾向

- **Instagram**：一番長く使っている。副業の集客用アカウント（顔は出さず、手元とイラストだけ）もある。
- **Threads**：Instagramから始めた。ここ1年で見る時間が増えた。共感系・つぶやき系が好き。
- **YouTube**：家事をしながら、ストレッチ系や「ゆる副業」系の動画を流し聞き。
- **LINE**：受講生との連絡用。
- フォローしているアカウントの傾向
  - 顔出ししていない副業ママ・在宅ワーカーの発信者（「子どもが寝たあとの1時間で〜」系）
  - Canva・ChatGPTの便利な使い方を図解する人
  - 一人で小さく商売をしている個人事業主（ハンドメイド、教室、サロン）
  - 「月100万」系の発信者は、最初はフォローしたが**怪しく感じて外した**経験がある
- 【00と重なる：時間を忘れてやれること＝SNS閲覧】ユーザー本人もSNSをよく見ているので、このペルソナのタイムラインの空気感を想像しやすい。

## 2. サブペルソナ

メインとの違い：**AIの理解度が「ほぼ未経験」**で、**会社のお金で契約する立場**（自分の財布ではない代わりに、社内の承認が必要）。

| 項目 | 内容 |
|---|---|
| 名前（仮） | 田村 ケンジ |
| 年齢・性別 | 42歳・男性 |
| 家族構成 | 妻と子ども2人（小学生） |
| 職業 | 従業員30人ほどの地方の工務店で総務。2年前から**広報・SNS・採用ページも兼務**（いわゆる一人広報） |
| 年収 | 約450万円（設定） |
| 住んでいる場所 | 静岡県の地方都市（車通勤） |
| AIの理解度 | **ほぼ未経験**。ChatGPTは「社長に言われてアカウントを作っただけ」。英語のツールは触ったことがない |
| 動画を作りたい理由 | 社長から「採用と施工事例の動画を出せ」と言われている。でも自分は顔を出したくないし、職人さんは撮影を嫌がる。社長も忙しくて撮影の時間が取れない。外注の見積もりは高くて通らなかった |
| これまでの挫折 | スマホで撮った施工事例の動画を出したが、ナレーションが無く再生されなかった。自分の声を入れるのは恥ずかしくてやめた |
| 制約 | **お金**：月額数千〜1万円程度なら稟議が通る可能性あり。ただしドル建て・カード払いは経理に説明が必要。インボイス対応の有無を聞かれる<br>**時間**：広報は業務の2〜3割。週に2〜3時間しか割けない<br>**知識**：AI・動画編集ともにゼロに近い。「社内で説明できる言葉」が欲しい |
| 決め手 | 「社長と経理に説明できるか」。料金・商用利用・肖像権・AI表示のルールが日本語でまとまっていると助かる |
| Threadsを見る時間 | 昼休み（12:00〜12:45）と、夜の21:00以降にスマホで |
| よく使うSNS | Facebook（地元の経営者つながり）、YouTube、会社のInstagram、Threadsは最近始めた |
| フォロー傾向 | 中小企業の広報・採用ノウハウ、地方の工務店の発信、AIで業務効率化を紹介する人 |
| 00との重なり | 会社員である点のみ。年代・AI経験は違う。**ユーザーには距離がある**ので、深追いせず「メインに向けた投稿が結果的に届く人」として扱うのがよい（推測） |

**メインとサブの使い分け（提案）**：ふだんの投稿はメインに向けて書き、月に数回「会社で使う場合」「社内で説明するときのポイント」の投稿を入れてサブを拾う。

## 3. ペルソナが絶対に言いそうな一言（フック用 10個）

1. 「顔出しさえできれば、もっと集客できるのに」
2. 「会社の人にバレたら終わる。だから顔は絶対出せない」
3. 「動画1本作るのに2時間。子どもが寝たあとじゃ続かない」
4. 「AIの動画って、見た人に『怪しい』って思われない？」
5. 「HeyGen、保存したまま3か月放置してる」
6. 「英語の画面とドル払いの時点で、そっと閉じた」
7. 「月額いくらまでなら元が取れるのか、誰か教えて」
8. 「顔出し前提のSNS講座、私には全部当てはまらなかった」
9. 「自分の声を入れるのも恥ずかしい。声もバレそう」
10. 「（サブ）社長に『動画やって』って言われたけど、誰が出るの？」

- 使い方の例：「『HeyGen、保存したまま3か月放置してる』って人へ。無料で試せる範囲を、実際にやった順番で書きます」のように、一言→具体的な手順や数字、の順でつなぐ。
- 注意：料金や無料プランの範囲は、投稿する前に必ず公式ページで確認し、確認した日付を添える（03でも料金情報が記事ごとに違うと指摘あり）。

## 4. 購入・申込までの心理の段階（メインペルソナ）

ここでの「購入・申込」は、主にHeyGenなどのAIアバター動画ツールの有料プラン契約（アフィリエイト経由）を想定しています。

| 段階 | ペルソナの頭の中 | 行動 | 刺さる投稿の方向性 | 離脱しやすいポイント |
|---|---|---|---|---|
| **認知** | 「顔出しなしで動画って作れるんだ」「AIの人が話してる動画、最近よく見る」 | 通勤電車でタイムラインを流し見。共感した投稿に「いいね」 | 悩みの代弁（フック一言集の1〜3、8）。「この投稿の動画もAIアバターで作りました」という実物 | 「月100万」系の誇張に見えると、すぐスクロールされる |
| **興味** | 「私でもできる？」「何分で、いくらで作れる？」「AIっぽさはどのくらい？」 | 投稿を保存。プロフィールを見に行く。過去の投稿をさかのぼる | 1本の制作時間・修正回数・かかった費用の記録（03の空白1）。失敗談や「AIっぽさ」の正直な比較 | 手順が多くて難しそうに見える。英語の画面のスクショだけで説明される |
| **比較** | 「HeyGenとほかのツール、どっちがいい？」「無料でどこまで？」「身バレしないアバターの選び方は？」「会社や家族にバレない支払い方は？」 | 夜22時以降に、保存した投稿を見返す。Googleで料金を調べる。他の人の口コミを探す | 「身バレしない度合い」でのアバターの選び方（03の空白2）。契約前に確認することリスト・日付付きの料金情報（空白3）。AI表示・PR表記の例（空白5） | 料金が記事ごとに違って不信感が出る。「結局いくら？」がわからないと保留になる |
| **行動** | 「まず無料で1本だけ作ってみよう」→「月◯本作るなら有料のほうがいい」 | 無料プランで試す→プロフィールのリンクやコメントの案内から有料プランを契約 | 「最初の1本はこの台本の型で」という手順の投稿。無料と有料の差を自分の使い方で説明 | 支払い画面（ドル建て・カード）で止まる。「夫に説明できない」と感じる |

### 段階ごとのメモ

- **行動の一歩目は「無料で1本作る」に設定する**のが現実的と考えられます（推測）。いきなり有料契約を勧めるより、「無料で試す→自分の講座の紹介動画が1本できた→続けたい」という流れのほうが、メインペルソナの「月数千円まで」「失敗したくない」という制約に合います。
- 無料プランの有無と範囲は、投稿の時点で公式ページで確認してください（**未確認**：今回は最新の無料枠を確認していません）。
- HeyGenのアフィリエイトは「新規契約から3か月間35%の継続報酬」（02_niche.md で公式ページを確認済み）なので、**契約後もすぐ解約されない**ように、契約したあとに役立つ投稿（台本の型、週◯本を回す手順）を続けると、ペルソナにとっても報酬の面でもよいと考えられます（推測）。
- サブペルソナの場合は、「比較」の段階に**社内の承認**が入ります。「社長・経理に説明するための1枚まとめ」（料金、商用利用、AI表示のルール）のような投稿が、行動への後押しになると考えられます（推測）。

### 表現上の注意

- 「顔出しなしで誰でも簡単に集客できる」「動画を出せば申込が増える」など、成果を約束する言い方はしない（景品表示法・ステマ規制）。
- アフィリエイトリンクを載せる投稿やプロフィールには「PR」と書く。
- AIアバター動画には「AIアバターです」と表示する運用を、発信者自身が見本として続ける（03の空白5）。

## 5. 次の工程（needs-analyst）への申し送り

- メインペルソナの一番強い悩みは「**顔出しできない（身バレ・副業バレ）×動画を作る時間がない**」の組み合わせです。ニーズ分析ではこの2つを軸にしてください。
- 決め手になりそうなのは「1本の制作時間」「月額料金と無料の範囲」「AIっぽさで信用が落ちないか」「身バレしないアバター・声の選び方」の4つです（推測）。
- 料金・無料プランの範囲・インボイス対応は**未確認**です。a8_programs_input.md に関連する案件（AI動画ツールなど）がある場合は、HeyGen以外の選択肢として確認してください。
- 市場規模（顔出しせずに動画を作りたい副業の個人事業主がThreadsにどれだけいるか）は引き続き**未確認**です。
