# アカウント設計（AI社員のリレー）

## 事前チェック
`threads-design/00_profile_input.md` を読み、職種・強み・AI経験・使える時間がほぼ空欄なら、先にユーザーに記入を頼んで止まる。

## 進め方
サブエージェントを下の順番で1人ずつ呼び出す。各担当が保存したファイルを次の担当が読む。

1. ジャンル選定AI → `01_genre.md`
2. 穴場ジャンル発掘AI → `02_niche.md`
   - **ここで一度止まり**、ユーザーに穴場トップ3を短く示して1つ選んでもらう。選択を `02_niche.md` の末尾に「決定：〇〇」と追記してから続ける
3. 競合分析AI → `03_competitors.md`
4. ペルソナ設計AI → `04_persona.md`
5. 顧客ニーズ分析AI → `05_needs.md`
6. コンセプト作成AI → `06_concept.md`
   - **ここで一度止まり**、コンセプト案をユーザーに見せて決めてもらう
7. ポジショニング設計AI → `07_positioning.md`
8. プロフィール設計AI → `08_profile.md`
9. プロフィール添削AI → `09_profile_review.md`

## 最後に
完成したプロフィール（アカウント名・自己紹介文・固定投稿）と、一言コンセプト、ポジショニング・ステートメントだけをユーザーに短く報告する。詳細は各ファイルを見てもらう。

## 設計の後（任意）
アカウント設計（1〜9）が完了した後、ユーザーが頼んだら以下を呼ぶ。

- A8案件分析AI → `12_a8_recommend.md`（「A8の案件を分析して」で起動。`a8_programs_input.md` に案件が貼られている前提。投稿作成AIが案件紹介の投稿を作る前に実行しておくと、より良い投稿になる）
10. 投稿作成AI → `10_posts_draft.md`（「投稿作成して」「投稿ネタ作って」で起動。本数の指定がなければ7本。各投稿は「状態：下書き」で作られる。`12_a8_recommend.md` があればそれを優先して使い、無ければ `a8_programs_input.md` の案件を使う。どちらも無ければカテゴリのみ示し、案件名はユーザーに確認を促す）
11. 投稿前チェックAI → `11_post_ready.md`（「投稿前チェックして」で起動。コピー用の最終確認シート）
   - 「投稿作成して」と言われたら、10 → 11 を続けて行う。投稿前チェックAIが「要修正」とした投稿は、その修正案を投稿作成AIに渡して書き直させ、もう一度投稿前チェックAIにかける（往復は最大2回。それでも要修正なら理由を添えてユーザーに判断を任せる）
   - 最後に `11_post_ready.md` の内容をユーザーに見せ、最終確認をお願いする
   - Threadsへの投稿はユーザーが最終確認して手動で行う。AIは投稿しない（自動送信はしない）
   - **「〇番を投稿した」「反応は〇〇だった」という事後報告は、投稿前チェックAIを呼ばず、Claude Code本体（この会話）が直接 `10_posts_draft.md`（状態を「投稿済み」に）・`post_ready/済/`（ファイル移動）・`11_post_log.md`（1行追記）を編集する。やり取りの往復を減らすため。** 複数件まとめての報告も1回でまとめて処理する。投稿前チェックAIを呼ぶのは、新しい投稿文案を実際にチェックする（内容の合否判定が要る）ときだけに限定する
   - 投稿時間は目安（朝7:30〜8:00、昼12:00前後、夜22:00〜23:30）を一度伝えれば足り、投稿のたびに時間を確認しない

## 他プラットフォームのコンテンツ（任意）
Threads以外のプラットフォームのコンテンツが空の場合、ユーザーが頼んだら以下を呼ぶ。

- note記事作成AI → `13_note_articles.md`（「note記事作って」で起動。noteのプロフィールリンクを機能させるために必要）
- Instagram投稿AI → `14_instagram_posts.md`（「Instagram投稿作って」で起動。画像生成プロンプト＋キャプションを作る。実際の画像生成・投稿はユーザーが行う）
- どちらも、できた下書きは投稿前チェックAIでチェックしてから使う（通常のチェック項目に加え、プラットフォームごとの文字数上限の違いに注意）

## 個別に使う場合
ユーザーが「競合分析だけやって」のように1人だけ指名したときは、その担当だけを呼ぶ。必要な前のファイルがなければ、その旨を伝える。
- 振り返り分析AI → `18_review.md`（「振り返りして」「投稿の数字を分析して」で起動。ユーザーが `17_metrics_input.md` に貼った数字を `11_post_log.md` に反映し、伸びた型・案件別の反応・収益化の見通しを分析する。数字が未入力なら止まる）
