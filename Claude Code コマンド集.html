Claude Code コマンド集
🔍

Claude Code で使えるスラッシュコマンドの一覧です。入力欄で / を押すと補完が表示されます。

基本操作 4
コマンド説明カテゴリ
/help ヘルプを表示する 基本
/clear 会話履歴を完全にクリアする 基本
/compact 会話を要約して保持しながら履歴をクリア（コンテキスト節約に有効） 基本
/exit Claude Code を終了する（/quit も同様） 基本
情報・ステータス 4
コマンド説明カテゴリ
/cost 現在のセッションのトークン使用量とコストを表示 情報
/status アカウント情報・使用中モデル・設定を表示 情報
/doctor Claude Code の健全性チェック（インストール状況・接続確認） 情報
/release-notes 最新のリリースノートを表示 情報
開発・コードレビュー 4
コマンド説明カテゴリ
/code-review コードレビューを実行。努力レベルを指定可能
/code-review low | medium | high | xhigh | max 		開発
/code-review ultra クラウド上でマルチエージェントによる深いレビュー。PR 番号指定も可能
/code-review ultra 123 		開発
/simplify 変更コードの簡素化・効率化・重複排除を提案し適用する 開発
/pr_comments 現在の PR のコメントを取得・表示する 開発
設定・モデル 5
コマンド説明カテゴリ
/config 設定画面を開く（テーマ・モデル・権限など） 設定
/model 使用するモデルを設定・変更する 設定
/permissions ツールの実行権限を管理する（自動許可・拒否の設定） 設定
/fast 高速モードの ON/OFF 切り替え（Opus ベースで高速出力） 設定
/vim Vim キーバインドモードの ON/OFF 切り替え 設定
プロジェクト・メモリ 4
コマンド説明カテゴリ
/init プロジェクトの CLAUDE.md ファイルを作成・初期化する プロジェクト
/memory メモリファイル（MEMORY.md）を編集・確認する プロジェクト
/todo Todo リストを表示・管理する プロジェクト
/bug Claude Code のバグを GitHub Issues に報告する プロジェクト
認証・セットアップ 4
コマンド説明カテゴリ
/login Anthropic アカウントにログイン・アカウントを切り替える 認証
/logout 現在のアカウントからサインアウトする 認証
/reset API キーをリセットする 認証
/terminal-setup ターミナル統合（シェル補完など）をインストールする 認証
一致するコマンドが見つかりません

CLI・ターミナル上でのキーボードショートカット一覧です。OS・シェルの種類により一部異なる場合があります。

Ctrl+C
操作をキャンセル
実行中のツールや生成を中断する
Ctrl+C×2
強制終了
Claude Code をすぐに終了する
↑/↓
入力履歴を移動
過去に入力したメッセージを呼び出す
Ctrl+R
履歴を逆順検索
過去の入力をインクリメンタルサーチ
Ctrl+L
画面をクリア
ターミナル表示をクリア（会話履歴は保持）
Shift+Tab
自動承認を解除
ツール実行の自動許可モードを一時停止する
Ctrl+]
最新アーティファクトを再表示
このセッションで最後に開いたアーティファクトをオープン
Enter
メッセージ送信
入力を確定して Claude に送信する
Shift+Enter
改行（送信しない）
複数行のメッセージを入力する
/
スラッシュコマンド
行頭で入力するとコマンド補完が表示される
💡 スキルは /skill-name の形式で呼び出します。タスクの内容に応じて Claude が自動的にロードすることもあります。

専門タスク用のスキル一覧です。各スキルは専用の指示セットをロードして動作します。

/code-review
現在の差分や PR をレビュー。
努力レベル (low / medium / high / xhigh / max / ultra) を指定できる
/simplify
変更コードの簡素化・効率化・重複排除を提案し適用する。品質特化（バグ検出は /code-review）
/init
コードベースのドキュメント付き CLAUDE.md を新規作成する
/run
プロジェクトのアプリを起動して変更内容を実際にテストする
/security-review
セキュリティの観点（OWASP など）からコードをレビューする
/claude-api
Claude API / Anthropic SDK のリファレンス（モデルID・価格・パラメータ・ストリーミングなど）
/update-config
settings.json の設定変更・フック追加・権限設定をガイド
/keybindings-help
キーボードショートカットのカスタマイズ・keybindings.json の編集
/plugin-authoring
Claude Code のプラグイン・パネル・バンド・スラッシュコマンドを作成する
/dataviz
チャート・グラフ・ダッシュボードなど、あらゆるデータ可視化を作成する前に自動ロード
/artifact-design
アーティファクト（HTML ページ）作成前のデザインガイダンスをロード
/artifact-capabilities
アーティファクトに DB・ライブデータ・共有状態などの動的機能を追加する
/schedule
定期実行するクラウドエージェントのスケジュール設定・管理
/loop
指定間隔でプロンプトやスラッシュコマンドを繰り返し実行する
/fewer-permission-prompts
トランスクリプトを分析して権限プロンプトを減らす allowlist を設定
/anthropic-skills:deep-research
Web 検索を組み合わせた深いリサーチを実行する

Claude Haiku 5.5
最速・最軽量モデル。シンプルなタスクや大量バッチ処理、コスト重視の用途に最適
claude-haiku-5-5
Claude Fable 5.1
ストーリーテリング・クリエイティブライティング特化モデル。創作・文章生成に
